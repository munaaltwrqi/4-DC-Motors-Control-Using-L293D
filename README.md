Four DC Motors Control Using L293D

Overview
This project demonstrates how to control four DC motors using an Arduino Uno and the L293D motor driver. The motors perform a sequence of forward, backward, and alternating right/left movements according to the assignment requirements.

Components
Arduino Uno
L293D Motor Driver
4 × DC Motors
Jumper Wires
Power Supply

Movement Sequence
Forward for 30 seconds.
Backward for 60 seconds.
Alternate between right and left turns for 60 seconds.
