# Four DC Motors Control Using L293D

## Overview
This project demonstrates how to control four DC motors using an Arduino Uno and the L293D motor driver. The motors perform a predefined sequence of movements according to the assignment requirements.

## Components
- Arduino Uno
- L293D Motor Driver
- 4 × DC Motors
- Jumper Wires
- Power Supply

## Movement Sequence
1. Move all four motors forward for 30 seconds.
2. Move all four motors backward for 60 seconds.
3. Alternate between right and left turns for 60 seconds by changing the rotation direction of the motors.
